Client Integrations

Configure your local development environments to instantly connect with Moor's Model Context Protocol hub. Select your preferred client below to inject the necessary connection configurations automatically.

terminal

Claude Code

Moor will securely update your ~/.claude.json to register local MCP toolsets. 

"mcpServers": {
  "moor-local": {
    "command": "moor",
    "args": ["serve"]
  }
}
edit_document

Cursor

Moor will inject server declarations into your active workspace's .cursor/mcp.json file. 

"mcpServers": {
  "moor-workspace": {
    "command": "moor",
    "args": ["connect", "--stdio"]
  }
}
code_blocks

Codex

Moor will generate and apply a TOML configuration block to your global codex.toml settings file. 

[mcp.servers.moor]
command = "moor"
args = ["agent", "--mode=codex"]
auto_start = true

OpenCode

Moor will synchronize your MCP endpoints directly into the opencode-settings.json configuration payload. 

"mcp_bridges": [
  {
    "name": "Moor System",
    "exec": "moor",
    "params": ["--bridge"]
  }
]
